# Hokie AI Builder Readiness clinic

**Purpose:** Run a free 20–30 minute practice clinic that helps participants inspect one AI-building habit, complete one drill, and leave with a concrete next step. Participation never requires an account or a public profile.

## Before participants arrive

- Open the deployed `/hokie` page on a phone and laptop; keep the low-bandwidth worksheet available.
- Choose a clinic code, such as `VTHACKS26`. Use the same code for the session.
- Read the consent language aloud: analytics are optional; VibeScore stores only the clinic code, a rotating pseudonym, coarse skill/band and completion events, an optional 1–5 usefulness rating, consent version, and timestamps. It does not store names, email, account handles, IP-derived identity, prompts, code, ANS queries, or agent IDs in the clinic dataset.
- State the retention period: participant mappings and events are deleted after 90 days. A participant can delete earlier using the deletion control tied to the token saved in their browser. Declining or deleting analytics does not limit the clinic.

## Run of show

| Time | Activity | Facilitator prompt |
| --- | --- | --- |
| 0–3 min | Welcome and optional consent | “You can complete everything without sharing analytics or publishing a profile.” |
| 3–6 min | Readiness check | Ask participants to answer from their normal workflow, not the “ideal” answer. |
| 6–16 min | Recommended drill | Pair participants if devices or bandwidth are limited. Use the worksheet when needed. |
| 16–23 min | Optional coding round | Emphasize verification and reflection rather than speed. |
| 23–27 min | ANS trust exercise | Identity, integrity and coverage are registry signals, not a safety guarantee. |
| 27–30 min | Follow-up and feedback | Invite a coarse follow-up band and optional 1–5 usefulness rating. |

## Low-bandwidth worksheet

1. Circle a baseline band: **Starting / Developing / Ready**.
2. Write one task you ask AI to help with.
3. Improve the task instruction with: desired outcome, relevant context, constraints, and a success check.
4. Write one verification step you would run before shipping.
5. Circle a follow-up band: **Starting / Developing / Ready**.
6. Optional usefulness rating: **1 2 3 4 5**.

Do not collect names or the written task instructions. At most, enter consented coarse bands, skill, completion signals and rating into VibeScore.

## Reporting rules

- Report denominators, response counts, data freshness and limitations alongside every rate.
- Suppress every live or synthetic cohort with fewer than ten distinct participants.
- Keep synthetic demonstrations separate and visibly labeled `synthetic`.
- Describe band movement as observed change. Do not claim that the clinic caused employment, interview or learning outcomes.
- Do not name a partner or quote a participant without separate approval and supporting evidence.

If the product or warehouse is unavailable, finish with the worksheet. Never copy worksheet prose into analytics. Record aggregate attendance outside VibeScore only when the event organizer has an approved process.
